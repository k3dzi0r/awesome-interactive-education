# Jak współtworzyć katalog

Dzięki za pomoc w rozwijaniu **Awesome Interactive Education**.

## Propozycja nowego zasobu

Najlepiej otworzyć Issue i podać:

- **Nazwa**
- **Adres URL**
- **Język**
- **Czy jest bezpłatny?**
- **Czy wymaga konta?**
- **Czy zawiera reklamy?**
- **Czy działa dobrze dotykiem?**
- **Czy działa offline?**
- **Czy można tworzyć własne ćwiczenia?**
- **Dla jakiej grupy / wieku może być przydatny?**
- **Krótki opis**

## Kryteria

Preferujemy zasoby:
- rzeczywiście przydatne w klasie,
- darmowe albo mające sensowną darmową wersję,
- przyjazne ekranom dotykowym,
- dostępne po polsku lub niewymagające znajomości języka,
- bezpieczne dla uczniów,
- bez agresywnych reklam,
- możliwie proste w obsłudze.

Nie dodajemy:
- samych landing page bez działającej darmowej funkcji,
- gier z agresywną monetyzacją,
- stron wymagających instalacji podejrzanych dodatków,
- serwisów pełnych reklam zasłaniających ćwiczenie,
- duplikatów już istniejących pozycji.

## Oznaczenia

Używamy:

- 🇵🇱 — polski
- 🟢 — darmowe
- 🟡 — freemium
- 🖐️ — tablica / dotyk
- 🧩 — puzzle / logika
- 🛠️ — tworzenie własnych ćwiczeń
- 💾 — offline
- 💻 — open source / self-hosting
- ♿ — szczególnie warte sprawdzenia w edukacji specjalnej

## Zmiany w istniejących wpisach

Jeśli serwis:
- przestał być darmowy,
- zmienił adres,
- wymaga teraz konta,
- został zamknięty,
- zaczął wyświetlać problematyczne reklamy,

otwórz Issue lub Pull Request.

Najważniejsza jest aktualność katalogu, nie jego długość.
